# Engineering Career Portfolio

손기석의 엔지니어 포트폴리오 저장소입니다.

이 저장소는 면접관과 채용 담당자가 손기석의 기술 방향, 강점, 프로젝트 성격을 빠르게 이해할 수 있도록 구성합니다.

## 핵심 소개

- Java/Spring 기반 백엔드 개발 경험
- Python/FastAPI 기반 API 및 데이터 처리 경험
- 데이터 플랫폼 및 AI 서비스 백엔드 연계 경험
- Linux, Docker, Nginx, Tomcat, Jenkins 기반 운영 반영 경험
- 정보보안 경력 기반의 DevSecOps, Application Security, 보안 자동화 차별화 요소 보유

## 현재 포지셔닝

손기석은 **Spring/Python 기반 데이터 플랫폼 백엔드 개발자**를 지향합니다.

단순 웹 기능 개발자가 아니라, 데이터 처리, API, 운영환경, 배포, 보안 관점을 함께 이해하는 플랫폼 백엔드 엔지니어로 포지셔닝합니다.

## 순수 백엔드가 아닌 데이터/AI 플랫폼 백엔드를 우선하는 이유

순수 백엔드가 맞지 않아서 제외하는 것이 아닙니다.

순수 백엔드로 포지셔닝하면 Java/Spring 개발 경력, 공공 SI 경험, 운영 반영 경험 중심으로 보일 수 있습니다. 이 경우 서비스 회사 백엔드 5년 이상, 대용량 트래픽, MSA, Kafka, Redis, Kubernetes, 코딩테스트 강점이 있는 후보들과 직접 비교됩니다.

반면 데이터 플랫폼 또는 AI 플랫폼 백엔드로 포지셔닝하면 다음 강점을 함께 설명할 수 있습니다.

- Java/Spring Boot 백엔드 개발
- Python/FastAPI 기반 API 개발
- Oracle/PostgreSQL/Hive/SQL
- 데이터 분석 결과의 웹 서비스화
- Text2SQL/RAG/LLM PoC
- Linux/Docker/Nginx/Tomcat/Jenkins 운영 반영
- 보안 경력 6년
- CISSP/정보보안기사/CPPG/SQLD

따라서 현재 방향은 다음처럼 정의합니다.

```text
순수 백엔드를 못해서 피하는 것이 아니다.
순수 백엔드로만 팔면 강점이 줄어든다.
보안 이해가 있는 데이터/AI 플랫폼 백엔드로 포지셔닝해야 제값을 받을 가능성이 높다.
```

## 목표 직무

1차 목표:

- 데이터 플랫폼 백엔드 개발자
- AI 플랫폼 백엔드 개발자
- Backend Platform Engineer
- Data Platform Engineer
- DevSecOps Engineer
- Application Security Engineer
- 사내 플랫폼 백엔드 개발자
- 보안 자동화 개발자

장기 선택지:

- IT 내부통제
- ITGC
- IT Risk
- IT Audit
- 감리

## 방향 변경 기준

2026-06 기준으로 PMO, 컨설팅, 감사 우선 전환보다 플랫폼 백엔드 이직을 우선합니다.

핵심 기준은 의존성입니다.

- PMO는 팀원, 고객, 일정, 정치에 대한 의존성이 높습니다.
- 컨설팅은 인터뷰 대상자와 고객 협조에 대한 의존성이 높습니다.
- 솔루션 엔지니어는 특정 제품과 어플라이언스에 대한 의존성이 높습니다.
- 개발은 코드, 구조, 로그, 배포, 운영을 통해 직접 산출물을 만들 수 있습니다.

따라서 현재 목표는 고객 대응과 조율 비중을 줄이고, 기술 산출물 소유 비중이 높은 플랫폼 백엔드 직무로 이동하는 것입니다.

## 폴더를 3개로 나눈 이유

이 저장소는 소개, 증명, 포지셔닝 순서로 읽히도록 구성했습니다.

### 01_profile

이 폴더는 손기석이 어떤 엔지니어인지 소개하는 영역입니다.

예시:

- `career-summary.md` : 경력 전체 요약
- `core-strengths.md` : 핵심 강점 정리
- `career-direction.md` : 앞으로의 기술 방향 설명

면접관이 처음 들어왔을 때 사람 소개를 빠르게 파악하는 폴더입니다.

### 02_projects

이 폴더는 실제로 무엇을 만들고 구현할 수 있는지 보여주는 영역입니다.

예시:

- `ai-rag-api/README.md` : 문서 기반 질의응답 API 프로젝트
- `text2sql/README.md` : 자연어 질의 SQL 변환 프로젝트
- `backend-platform-template/README.md` : 운영형 백엔드 템플릿
- `security-audit-log/README.md` : 감사로그/권한통제 예제

말로 소개한 역량을 실제 결과물로 보여주는 기술 증명 폴더입니다.

### 03_portfolio

이 폴더는 어떤 포지션에 적합한지 채용 관점에서 정리하는 영역입니다.

예시:

- `portfolio-overview.md` : 전체 포트폴리오 개요
- `backend-ai-engineer.md` : 백엔드 + AI 응용 엔지니어 포지셔닝
- `security-backend-platform.md` : 보안 + 백엔드 + 플랫폼 특화 포지셔닝

프로필과 프로젝트를 묶어서 채용 관점으로 해석해주는 포지셔닝 폴더입니다.
