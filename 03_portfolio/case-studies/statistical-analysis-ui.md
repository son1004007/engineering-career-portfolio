# Java/Spring 통계 품질 분석 화면

> 상태: `source-reviewed` · 추가 업무 계정 소유 확인 완료 · 공개 재현은 아직 없음

## 확인된 범위

추가 업무 계정이 본인 계정임을 소유자가 확인했고, 비공개 Java/Spring 코드에서 통계 품질 분석 화면의 데이터 처리와 시각화 관련 직접 기여 일부를 확인했습니다. 전체 시스템이나 분석 알고리즘을 단독 구현한 것으로 표현하지 않습니다.

## 문제

CSV·Excel에서 읽은 측정값을 그룹 단위로 집계하고 Xbar-R 차트에 전달하려면 업로드 형식, 결측값, 그룹 크기와 표시 순서를 일관되게 처리해야 합니다. 화면이 그럴듯하게 보이는 것과 통계 결과가 재현되는 것은 다른 검증 문제입니다.

## 설계 판단

- 업로드 파싱, 도메인 검증, 통계 계산과 차트 DTO 생성을 분리합니다.
- 원본 행 번호와 오류 사유를 보존해 잘못된 입력을 추적할 수 있게 합니다.
- 계산 결과와 차트 표현을 같은 객체에 숨기지 않습니다.
- 알려진 소규모 데이터셋의 기대값으로 계산을 먼저 검증합니다.

## 공개 재현 계획

합성 측정값으로 CSV 업로드, 그룹 집계와 공개 수식 기반 Xbar-R 계산을 구현합니다. 빈 파일, 숫자가 아닌 값, 그룹 크기 불일치와 경계값을 테스트하고 차트에는 계산 완료 DTO만 전달합니다.

## 한계

현재 공개 글은 확인된 일부 기여를 설명합니다. 통계 정확도, 실제 운영 규모와 전체 화면 구현을 주장하지 않으며 독립 테스트 전에는 `source-reviewed`를 유지합니다.
