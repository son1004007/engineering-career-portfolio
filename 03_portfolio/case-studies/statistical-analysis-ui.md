# Java/Spring 통계 품질 분석 화면

## 문제

CSV·Excel에서 읽은 측정값을 그룹 단위로 집계하고 Xbar-R 차트에 전달하려면 업로드 형식, 결측값, 그룹 크기와 표시 순서를 일관되게 처리해야 합니다. 화면이 그럴듯하게 보이는 것과 통계 결과가 재현되는 것은 다른 검증 문제입니다.

## 담당한 부분

비공개 Java/Spring 코드에서 본인이 담당한 통계 품질 분석 화면의 데이터 처리와 시각화 연결 범위를 확인했습니다. CSV·Excel 입력을 화면 데이터로 변환하고 분석 결과가 차트까지 일관되게 전달되는 흐름 가운데 확인된 일부 구현을 다룬 사례입니다.

## 설계 판단

- 업로드 파싱, 도메인 검증, 통계 계산과 차트 DTO 생성을 분리합니다.
- 원본 행 번호와 오류 사유를 보존해 잘못된 입력을 추적할 수 있게 합니다.
- 계산 결과와 차트 표현을 같은 객체에 숨기지 않습니다.
- 알려진 소규모 데이터셋의 기대값으로 계산을 먼저 검증합니다.

## 현재 공개 범위

회사 데이터와 원본 코드, 실제 화면은 포함하지 않았습니다. 현재 글은 확인된 일부 기여와 설계 판단만 설명하며, 전체 시스템이나 분석 알고리즘의 단독 구현, 통계 정확도와 운영 규모를 검증한 결과를 의미하지 않습니다. 공개 재현 코드와 독립 테스트도 아직 포함하지 않습니다.
