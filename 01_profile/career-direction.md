# Career Direction

## 현재 방향

손기석은 **Java/Spring 엔터프라이즈 백엔드·플랫폼 엔지니어**를 지향합니다.

단순 웹 기능 개발자가 아니라, 백엔드 개발, 데이터 처리, API 연계, 운영환경 구성, 배포, 장애 대응, 보안 관점을 함께 이해하는 플랫폼 백엔드 엔지니어로 포지셔닝합니다.

이 방향은 최신 키워드를 따라가기 위한 선택이 아니라, 지금까지 축적한 백엔드·데이터·운영·보안 경험을 가장 잘 결합하는 선택입니다.

---

## 왜 이 방향을 선택했는가

### 1. 설계부터 운영 개선까지 기술 산출물을 소유한다

요구사항을 코드와 운영 가능한 구조로 바꾸고, 테스트·로그·배포 결과로 품질을 설명할 수 있는 역할을 우선합니다. 협업과 조율 경험은 이 과정을 돕는 강점으로 사용하며, 핵심 평가는 직접 설계하고 구현·검증한 산출물에 둡니다.

### 2. 백엔드는 현재 가장 강한 기반이다

현재 가장 강한 축은 Java/Spring 기반 백엔드 개발, DB 연계, API 설계, 운영 반영입니다.

따라서 커리어의 중심은 계속 백엔드에 두는 것이 가장 현실적입니다.

### 3. 데이터/플랫폼 역량은 오래 남는 자산이다

AI 유행과 별개로 데이터 흐름, 검색, 배포, 운영, 플랫폼 구조를 이해하는 능력은 장기적으로 남는 역량입니다.

그래서 일반 백엔드보다 데이터 플랫폼과 플랫폼 백엔드 방향이 더 적합합니다.

### 4. AI는 연구가 아니라 서비스화 관점에서 활용한다

LLM 챗봇 PoC, Text2SQL, 문서 기반 AI 서비스 구조 검토 경험은 모델 연구보다 서비스/API 연계 관점에서 활용합니다.

즉, 목표는 AI 연구원이 아니라 AI 기능을 서비스와 데이터 흐름에 연결하는 백엔드 엔지니어입니다.

### 5. 보안 경력은 차별화 포인트가 된다

보안 경력과 자격증, 통제/감사/운영 맥락을 이해한 경험은 일반 백엔드 개발자와 다른 강점입니다.

따라서 보안은 버릴 과거 경력이 아니라 DevSecOps, Application Security, 보안 자동화, 접근통제, 감사로그 개발로 연결할 수 있는 자산입니다.

## 커리어 방향 3축

### 1. 메인 전략

**플랫폼 백엔드 개발자**

- Java/Spring 기반 백엔드
- Python/FastAPI 기반 API 및 데이터 처리
- SQL, DB 연계, 데이터 흐름 구현
- Linux, Docker, Nginx, Tomcat, Jenkins 기반 운영 반영
- 설계, 코드, 테스트와 운영 개선을 직접 연결하는 역할

### 2. 확장 전략

**데이터 플랫폼 / AI 플랫폼 백엔드**

- 데이터 분석 결과의 서비스화
- RAG, Text2SQL, 문서 기반 질의응답
- API, DB, 문서, 검색, 로그 연계
- 플랫폼형 서비스 백엔드 구조 설계와 구현

### 3. 차별화 전략

**보안 + 백엔드 + 플랫폼 특화형**

- DevSecOps
- Application Security
- Secure SDLC
- 접근권한 관리
- 감사 로그
- 보안 자동화
- 개인정보보호 시스템
- 로그/통제/감사 중심 서비스 구조 이해
