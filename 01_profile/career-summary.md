# Career Summary

손기석은 **Java/Spring 기반 엔터프라이즈 백엔드를 중심으로 Python/FastAPI와 AI Agent 기능을 업무시스템에 연결하는 백엔드·플랫폼 엔지니어**입니다.

공공 및 데이터 분석 서비스 프로젝트에서 웹 애플리케이션, API 서버, DB 연계, 운영 반영, 배포 구조를 다뤄왔습니다. 2026년에는 **FastAPI 기반 Text2SQL/NL2SQL 서비스와 다중 모델 benchmark**, **Agentic AI Runtime의 작업 격리 및 artifact/provenance 추적 구성요소**, **LLM 기반 분석 workflow**를 연속적인 핵심 업무 축으로 수행했습니다.

단순 기능 구현만이 아니라,
- 데이터 분석 결과를 실제 서비스 기능으로 연결하고
- 운영 가능한 개발 구조를 만들고
- 협업 체계와 실행 환경을 정리하며
- 필요할 때는 보안·권한·감사 관점까지 함께 고려하는

실무형 엔지니어를 지향합니다.

포트폴리오는 신규 `OpsMate Local`로 AI Agent 통합 역량을 증명하고, 기존 업무의 비식별 사례 게시물과 독립 재현 코드로 Java/Spring 실무 깊이를 증명하는 두 트랙으로 구성합니다.

## 핵심 포지셔닝
- Java/Spring 엔터프라이즈 백엔드·플랫폼 엔지니어
- 기업 업무시스템과 AI Agent를 연결하는 백엔드 엔지니어
- AI/LLM 응용서비스 백엔드 엔지니어
- LLM 서비스 통합 및 AI Runtime 백엔드 엔지니어
- Java/Python 기반 데이터 및 AI 제품 백엔드 엔지니어
- 보안 + 백엔드 + 플랫폼 결합형 엔지니어

- Java, Spring Boot

Java/Spring의 서비스·트랜잭션·인증·운영 역량을 핵심 기반으로 유지하고, Python/FastAPI와 AI Agent의 구현·통합·평가 역량을 확장합니다. 모델 연구나 학습보다 엔터프라이즈 데이터와 LLM을 안전하고 검증 가능한 서비스로 연결하는 방향을 지향합니다.
