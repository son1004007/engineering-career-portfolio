# Career Summary

손기석은 **Java/Spring 기반 엔터프라이즈 서비스 경험 위에 Python/FastAPI 기반 AI/LLM 응용서비스를 구현하는 백엔드 엔지니어**입니다.

공공 및 데이터 분석 서비스 프로젝트에서 웹 애플리케이션, API 서버, DB 연계, 운영 반영, 배포 구조를 다뤄왔습니다. 2026년에는 **FastAPI 기반 Text2SQL/NL2SQL 서비스와 다중 모델 benchmark**, **Agentic AI Runtime의 작업 격리 및 artifact/provenance 추적 구성요소**, **LLM 기반 분석 workflow**를 연속적인 핵심 업무 축으로 수행했습니다.

단순 기능 구현만이 아니라,
- 데이터 분석 결과를 실제 서비스 기능으로 연결하고
- 운영 가능한 개발 구조를 만들고
- 협업 체계와 실행 환경을 정리하며
- 필요할 때는 보안·권한·감사 관점까지 함께 고려하는

실무형 엔지니어를 지향합니다.

## 핵심 포지셔닝
- AI/LLM 응용서비스 백엔드 엔지니어

Java/Spring은 서비스와 운영의 기반으로 활용하고, Python/FastAPI 기반 AI 응용의 구현, 통합, 평가 역량을 주력 전문성으로 발전시킵니다. 모델 연구나 학습보다 엔터프라이즈 데이터와 LLM을 안전하고 검증 가능한 서비스로 연결하는 방향을 지향합니다.
